Online Farmer Hub – Project Description

Online Farmer Hub is a web-based agricultural marketplace developed using Python Django and MySQL. The platform connects farmers (sellers) directly with buyers, making the process of buying and selling agricultural products simple, secure, and transparent. It eliminates unnecessary middlemen, ensuring better prices for farmers and fresh products for customers.

The system consists of four modules:

- Admin Module: Manages the entire system by approving seller registrations, managing product categories, approving or rejecting products, and monitoring users and orders.
- Seller Module: Allows farmers/sellers to register, upload their products with images, manage stock, update product details, and track customer orders.
- Buyer Module: Enables customers to browse products, add items to the cart or wishlist, place orders, make payments, provide delivery details, and submit ratings and feedback after purchase.
- Hub Module: Manages the delivery process by updating order statuses such as Confirmed, Shipped, Out for Delivery, and Delivered. Buyers receive email notifications whenever the delivery status changes.

The application includes features such as seller approval, category management, product management, shopping cart, wishlist, online booking, order management, delivery tracking, customer feedback, and email notifications.

Technologies Used:

- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: Python
- Framework: Django
- Database: MySQL
